# MY ZONE · 绝区零风格个人主页

这是一个纯静态网页，不需要安装依赖。

## 本地预览

直接双击打开 `index.html` 即可；如果浏览器限制本地脚本，也可以在当前目录运行：

```bash
npx serve .
```

## 文件结构

- `index.html`：五个页面的文字内容都在这里修改。
- `css/style.css`：配色、版式、动效和响应式样式。
- `js/main.js`：H.D.D 开屏、线框背景、页面路由和属性条动画。

## 主要可改内容

- 首页名字：搜索「你的名字」。
- 个人资料：修改 `data-page="profile"` 里的坐标、身份和自我介绍。
- 兴趣爱好：修改 `data-page="hobby"` 里的六张卡片。
- 个人阅历：修改 `data-page="experience"` 里的时间线。
- 性格属性：修改性格页里的 `data-val` 数值，范围 0–100。

## 开屏设置

- 开屏时长在 `js/main.js` 里的 `INTRO_MS` 调整，当前约 6.2 秒。
- 同一个浏览器会话内只自动播放一次；右上角「开屏」按钮可以手动重播。
- 想让每次刷新都播放，可以删除 `sessionStorage` 相关判断。
